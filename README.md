# Finance Friend

Build a modern AI Personal Finance Tracker as a complete multi-page web application.

The application should have a professional fintech design using green, white, and dark gray colors with rounded cards and clean spacing.

Create separate pages using routing.

Pages required:

1. Landing Page

2. Login

3. Register

4. Dashboard

5. Transactions

6. Savings Goals

7. AI Assistant

8. User Profile

Use a sidebar for navigation after login.

The application should be fully responsive.

This project was built with [Lovable](https://lovable.dev).
